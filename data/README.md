# Data

* **The dataset we selected for this project is "what we watched on Netflix". It comes from the reports Netflix puts out on its own where they share how many hours people spent watching each show and movie. They have been releasing these every six months since mid 2023. We are using four of these reports together so our data ranges from the second half of 2023 to the first half of 2025.**



# Codebook for Movies and Shows Dataset

## Variable Names and Descriptions:

* **variable**: Description
* source: Source file name
* report: Report period
* title: Movie title
* available\_globally: Whether the movie is available globally or not
* release\_date: Movie release date
* hours\_viewed: Hours spent viewing the movie
* runtime: Movie runtime
* views: Hours viewed / runtime

## Data Types:

* **Column**: data type
* source: character
* report: character
* title: character
* available\_globally: character
* release\_date: date
* hours\_viewed: double
* runtime: Period
* views: double
